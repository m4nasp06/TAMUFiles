Q1: Print Age

Write a Python program (called q1.py) that asks the user for their name and age. Then the program greets them using howdy and tells how old they will be in the next year. Below are examples of output when the program is executed.
Note: To print an empty line, use print() or ‘\n’. Use int function to convert text input to integer. Run given tests locally before submitting. It will save you a lot of time. Local runs are a lot faster than gradescope submissions.

Example #1. At the prompt “Enter your name”, the user enters John (line 1). The user then enters 20 at the age prompt (line 2). The greeting is printed on line 4. The age next year is printed on line 5.

Enter your name: John
Enter your age: 20

Howdy, John 
Next year, you will be 21 years old.

 

Example #2.  Similar to Example #1 but with different input.

Enter your name: Sarah
Enter your age: 24

Howdy, Sarah
Next year, you will be 25 years old.

 

Q2: Calculate Radius

Write a program (called q2.py) that takes the area of a circle as input and prints its radius as output. Area of a circle is A = 𝝅r2, where r is the radius. Therefore, radius can be calculated as r = A. Use the 𝜋 value = 3.1416 for the calculation. Below are examples of output when the program is executed. Note: You can use a ** 0.5 to compute a. To convert text input from user to a floating point number (real number), you can use the float function similar to how int function is used to convert text to numbers.

Example #1. At the prompt “Enter area of a circle”, the user enters 12 (line 1).

Then the radius is printed on line 3.

Enter area of a circle: 12
Radius of a circle with area 12.0 is 1.95

Example #2.  Similar to Example #1 but with different input.

Note: Round the results to two decimal places before printing. 

Q3: Time

Write a program (called q3.py) that asks for the number of seconds as input. Your program needs to convert them into corresponding hours, minutes and seconds. Relation between these metrics are 60 seconds = 1 minute and 60 minutes = 1 hour.

Notes:

Dividing a number by 60 will give you a floating-point number, i.e. 137 / 60 = 2.283333333333333. You can use the int function to remove the decimal part of the number, i.e. int(2.28333) = 2 and int(2.67000) = 2.  You can then calculate the number of remaining minutes or seconds by doing: (137 - (60 * 2)) = 17.

Using variables for intermediate calculation will help you in solving the problem. We will cover integer division and modulo operation in the next lecture which will make the process easier.

 

Example #1.  At the prompt “Enter number of seconds”, the user enters 137 (line 1).

The output is printed on line 3.

Enter number of seconds: 137

137 seconds = 0 hours, 2 minutes and 17 seconds

 

Example #2.  Similar to Example #1 but with different input.

Enter number of seconds: 4861

4861 seconds = 1 hours, 21 minutes and 1 seconds

 

Example #3.  Similar to Example #1 but with different input.

Enter number of seconds: 32 

32 seconds = 0 hours, 0 minutes and 32 seconds
