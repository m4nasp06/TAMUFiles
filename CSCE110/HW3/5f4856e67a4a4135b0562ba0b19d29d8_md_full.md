In this question, you will build the core backend logic for a retail inventory system (like the one used at Walmart or Target). This system will manage product details (suppliers and prices), track physical stock levels on shelves, process customer sales, and generate financial reports.

Everything will be written in Hw03.py. You are not allowed to use loops, conditional statement, and any other programming constructs not discussed in class yet. Using built-in function such as len, sum, etc. is allowed.

##  Global Data Structures

At the very top of your file, initialize the following three global variables.

● inventory : Initialized to an empty dictionary. The keys will be strings containing item names. The values will be integers representing the quantity of item in the inventory.





● products: Initialized to an empty dictionary. The keys will be strings containing item names.

The values will be lists where the first item is a string containing supplier name, and the second item is a float containing price of the item.

● storeName : A string containing store name. This should be initialized to "Walmart".
